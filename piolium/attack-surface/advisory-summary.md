### Supply Chain Risk Observations

1. **Package installer (`package_install.rs`)** downloads from crates.io, npmjs.org, PyPI, and Go proxy. Any compromise of these registries or dependency confusion attacks could lead to arbitrary code execution through the build/install flow.
2. **`PackageInvokeSpec`** in `package_install.rs` allows specifying arbitrary program and args for package execution — this is a potential command injection surface if an attacker can control package metadata.
3. **Plugin loading** via `dynamic_module/unix.rs` uses `libloading::Library::new(path)` — loading from uncontrolled paths would give attackers full code execution.
4. The project has **no vendored dependencies** beyond the `vendor/` directory (which appears minimal).
